# 本地网络与蓝牙兼容组件

PTV 与此 APK 必须使用同一签名。普通应用通过受签名权限保护的服务访问网络操作；本地管理服务由安装工具通过 ADB shell 启动，仅处理 Wi-Fi 配置删除和蓝牙管理等固定操作，不提供通用命令执行接口。

Android 14 上，target 28 的连接组件可以直接连接 Wi-Fi，但无法删除其他身份创建的配置。此时转交 shell 服务，校验网络 ID 与 SSID 后删除，并读取配置确认结果。诊断接口仅创建随机名称的未连接临时配置，60 秒后清理，不切换当前网络。

管理服务通过仅允许 shell 注册的 ContentProvider 交接 Binder；请求端校验兼容组件 UID 与 PTV 签名。应用不直接连接 shell Unix socket，以兼容电视的 SELinux 隔离。

蓝牙状态来自配对、Profile 和 ACL 状态，操作被系统接受后继续观察真实状态；拒绝、超时会显示失败。断开、忽略和关闭蓝牙会确认，避免误操作遥控器。配对确认仍可能需要 Android 系统确认。

电视重启后服务失效，需要通过安装工具重新激活。服务未激活时明确提示，不将未执行的操作显示为成功。

实机验证：MiTV-MFTR0 / Android 14，异 UID 临时 Wi-Fi 配置删除、当前连接保持、蓝牙只读状态与详情页焦点恢复均通过。真实蓝牙配对、连接、断开和忽略需要备用设备验收。
