# PTV Launcher

为小米电视打造的遥控器桌面：Apple TV 风格的左侧透明图标栏、全局快捷切换与必应画报。Kotlin / Android 原生 View，最低 Android 7.0（API 24）。实机适配基准：MiTV-MFTR0，Android 14，OS3.0.102.0，1920×1080。

## 使用

- 方向键选择，确定键打开应用；应用直接全屏运行。
- 常用栏最多固定 10 个应用，卡片基础尺寸固定为 112×63dp，数量增加时通过上下滚动浏览。列表末尾有 AppList 图标按钮，确定打开全部应用；也可在常用栏按左键打开。长按确定在当前图标旁展开无整体底板的 iOS 风格图标菜单（每个按钮有不透明圆形底色，排序为三横线，当前焦点显示白色高亮）：从桌面移除（未固定时为添加到桌面）、编辑排序、应用信息；左右选择、返回收起，并带展开和收起动画。选择编辑排序后上下调整位置，确定完成。AppList 顶部的“管理桌面应用”进入管理模式，按确定添加或移除当前应用；蓝色勾选代表已在桌面，最多 10 个，选择“完成”或返回退出管理。
- 右上角桌面设置 → 自定义桌面应用，可逐个选择桌面图标；已满 10 个时先移除再添加。卸载应用自动清理固定记录。
- 右上角齿轮打开桌面设置；常用栏第一项按上键保持焦点。返回键收起当前面板。
- 应用内长按返回键 600ms 打开切换栏；短按正常返回。切换栏从屏幕左侧滑入、向左滑出。浮层与桌面使用同一套透明图标栏，无整块背景、无全屏遮罩，保持电视画面可见。左键或末尾 AppList 按钮展开全部应用；弹窗内返回收起弹窗并回到原卡片／AppList 按钮，再按返回关闭浮层。浮层第一项按上键保持焦点，不退出当前应用。
- PTV 主页短按菜单键即调用小米 SmartPanel 的原生控制中心入口，在按下时触发，不必长按或等待松开；同一手势的重复和松开事件不重复打开。无障碍服务仅在 PTV 窗口获得焦点时补充处理桌面菜单键；其他应用和原生控制菜单的菜单键保持原有行为。PTV 不绘制控制中心，也不主动关闭原生菜单。
- 右上角桌面设置 → 快捷切换，打开系统无障碍设置，启用 **PTV 快速切换**，授权处理返回键。页面区分未启用、已授权但未连接、已连接；未连接时需重新开启服务，不能只凭授权列表判断可用。
- 右上角桌面设置 → 默认桌面 → 设为默认桌面，在系统窗口中选择 PTV Launcher。页面会显示当前选择状态，并在小米系统需要转接时提示启用主页键兼容；也可从这里更改回原桌面。
- 壁纸默认每 30 秒轮播；桌面闲置 3 分钟展示画报。可在设置中调整等待时间或关闭。任意键仅退出画报，不误启动应用。

应用内控制中心已删除。画面、声音、信号源等功能使用电视原生菜单。未启用无障碍服务时仍可使用桌面、画报和应用启动。

## 构建与安装

要求 JDK 21、Android SDK 36.1，Gradle Wrapper 已随项目提供。

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.popkter.ptvlauncher/.MainActivity
```

连接真机后运行存储持久化及应用枚举验证：

```sh
./gradlew :app:connectedDebugAndroidTest
```

调试 APK 使用开发签名。正式公开发布前应使用维护者自己的 release 签名，并保管密钥；项目不包含发布私钥。

## 默认桌面与恢复

优先使用应用中的系统默认桌面选择入口。当前小米固件即使授予 HOME 角色仍会强制打开原桌面，因此 PTV 在已持有 HOME 角色且无障碍服务启用时，将系统强制打开的原桌面转接回 PTV。恢复原默认桌面后转接自动失效。若固件限制选择器，可通过 ADB 设置（不需要停用原桌面）：

```sh
adb shell cmd package set-home-activity com.popkter.ptvlauncher/.MainActivity
adb shell am start -n com.popkter.ptvlauncher/.MainActivity
adb shell input keyevent KEYCODE_HOME
```

本机小米桌面的恢复入口如下，其他固件应先查询 HOME 组件：

```sh
adb shell cmd package set-home-activity com.mitv.tvhome/.MainActivityUserMode
adb shell am start -n com.mitv.tvhome/.MainActivityUserMode
```

卸载前先恢复原桌面，并在系统无障碍设置中关闭 PTV 快速切换。原桌面一直保留。

## 隐私与资源

无账号、广告、统计或遥测。应用排序保存在本机 DataStore；只在本机枚举已安装应用。无障碍服务处理遥控器按键和窗口包名。系统不支持跨窗口模糊时，打开浮层会截取一帧背景，在内存中模糊；不保存或上传截图、按键或使用记录。受保护的画面无法截取。启用此服务会由 PTV 处理短按返回，再执行系统返回动作，具体系统应用的特殊返回行为需要实机验证。

壁纸通过 HTTPS 从 Bing 获取，最多缓存八张；断网使用缓存，无缓存时展示本项目原创 Canvas 山景。离开桌面暂停轮播与画报计时。缓存可能被系统回收。Bing 图片版权属于原作者／相关权利人，不适用本项目代码许可，也不随 APK 分发。服务不可用时画报功能自动使用本地背景。

不嵌入第三方应用，不接管系统屏保，不提供 Root／隐藏 API 功能。AppList 使用全屏平滑模糊，切换栏保持透明。无法获取截图时保留透明背景。

## 设计与兼容性

界面参考 Apple 的 [tvOS 设计指南](https://developer.apple.com/design/human-interface-guidelines/designing-for-tvos) 与 [焦点与选择规范](https://developer.apple.com/design/human-interface-guidelines/focus-and-selection)，使用 16:9 原生电视横幅卡片、外层玻璃焦点高光、适度缩放、清晰层级和局部玻璃材质。实现为独立 Android 代码，参考 [Apple TV 导览手册](https://support.apple.com/zh-cn/guide/tv/atvbe55a4b4e/tvos) 和用户提供的卡片截图；未复制 Apple 组件、字体或品牌素材；字体使用电视系统字体。桌面和应用内窗口共用原生 View 图标栏、可回收的 GridView 应用网格及应用列表组件。

主页使用已验证固件的 SmartPanel 导出服务入口；其他设备若未提供该入口会提示不可用。其他应用的菜单键仍由电视固件和前台应用处理。

## 原生版性能调整

使用 Activity、原生 View 和回收可见项的 GridView。卡片与浮层共享实现，保持用户现有应用选择与排序。时钟局部更新，图片在线程中解码；无障碍按键回调先返回拦截结果，再异步创建切换栏。

1.1.1-native 进一步取消主页转接中的固定等待和切换动画。当前小米固件仍先启动原桌面，再转接 PTV；无法保证零闪跳。原因、验证数据和限制见 [主页路由调查](docs/HOME_ROUTING.md)。

1.2-native 使用固定尺寸的可滚动卡片栏，列表末尾增加 AppList 图标；AppList 去掉面板边界、底色和阴影，桌面以全屏模糊壁纸衬托五列宽幅卡片，支持“所有 App／主屏幕”筛选、焦点放大和完整行滚动。应用内仅在系统支持时启用跨窗口模糊；当前小米固件返回不支持，保持透明显示原应用。桌面与应用内浮层共用同一套组件，切换栏透明背景保持不变。

## 平滑模糊与系统菜单

- AppList 在适配电视的 960×540dp 视口内完整显示三排、每排五个应用，更多应用继续滚动。
- 用 480px 宽的三次可分离盒式滤波替代 64×36 缩略图放大；图片和截图处理在后台执行。
- HOME 在固件派发按键时优先直接拦截；系统仍强制解析原桌面时保留窗口转接。该优化不等于取得系统应用身份，是否消除实体遥控器闪跳需真机确认。详见 docs/HOME_ROUTING.md。

主屏幕时钟（1.3.10-native）：移到壁纸右上方的独立区域，采用 76sp 中等字重数字、等宽数字排版与轻微阴影，取消原右上角小号时间。时间数字右边缘与右上角设置按钮对齐，顶部与首个应用图标的正常尺寸顶部对齐。时钟没有背景面板，不参与遥控器焦点；打开 AppList／桌面设置时随主屏幕信息隐藏。

图标统一使用 Framework7 Icons 5.0.5（MIT）矢量资源。该图标库仅用于功能按钮。桌面、浮层和 AppList 应用卡片使用原始品牌图标，由 AppIconArtwork 等比居中绘制并裁切为圆角矩形；逐行采样原图左右边缘并分别延续颜色，补齐透明圆角下的背景；主色仅用于无法取得边缘颜色时回退，不拉伸图标、不使用 TV 横幅。

米家电视版：部分 HyperOS 固件的米家（com.xiaomi.smarthome.tv）没有 LAUNCHER／LEANBACK_LAUNCHER 分类，但提供公开的 com.xiaomi.smarthome.tv.action.MAIN 页面入口。PTV 先检测已安装版本的导出入口及调用权限，将其归入可打开的 App；可在 AppList 中打开、添加到桌面和排序。仍使用原米家图标与系统账号；不另装手机米家。其他未识别入口的系统组件保持仅查看。

应用商店：同类适配包含 com.xiaomi.mitv.appstore 的公开 mitv.appstore.action.LAUNCHER 入口。应用商店在当前固件中显示为“应用中心”，可以从 AppList 直接打开及固定；商店内搜索、安装、更新继续由小米原生应用处理。

### 扫码上传自定义壁纸
桌面设置 → 壁纸，可选择必应壁纸轮播，或自定义壁纸。进入“扫码上传壁纸”，手机与电视连接同一局域网后扫码；支持多选 JPG/PNG/WebP，每张最多 12 MB，共最多 30 张。上传页面关闭后链接失效；图片保存在电视应用私有目录，不上传云端，不随缓存清理删除。支持每 30 秒轮播全部图片，或在右侧四列相册固定一张、批量勾选删除。选择“排序”后确定拿起图片，方向键移动、确定放下；顺序保存在本地并作为轮播顺序。照片按 EXIF 方向校正并缩小存储；自定义图片为空时显示默认风景。

遥控器快捷切换开启时使用低优先级、无声的前台服务通知，避免部分小米固件在其他视频应用中冻结 PTV、延迟按键松开并产生额外连发。关闭长按返回开关会撤销此前台服务通知。
